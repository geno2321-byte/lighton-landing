3. YouTube API 서비스 이용

플로우랩은 YouTube API 서비스를 이용합니다. 이용자가 서비스를 쓰면 YouTube 서비스 약관에 동의하는 것으로 봅니다. YouTube가 다루는 정보는 Google 개인정보처리방침을 따릅니다. 플로우랩은 YouTube 또는 Google이 운영하거나 보증하는 서비스가 아닙니다.

  • 서비스는 YouTube Data API로 공개된 영상·채널 정보만 가져옵니다. 이용자의 개인 YouTube 데이터는 가져오지 않습니다.
  • 가져온 정보는 이용자 화면에 보여 주고, 이용자가 저장하기를 누른 결과를 이용자 계정에 연결해 보관하는 데만 씁니다.
  • 회사는 YouTube API 서비스로 얻은 데이터를 30일을 넘기지 않고 갱신하거나 삭제합니다. 이용자가 저장한 결과도 같은 원칙으로 갱신·삭제됩니다.
  • 이 데이터를 광고에 쓰거나 제3자에게 판매하지 않습니다. 서비스 제공에 필요한 처리 위탁과 전송은 아래 제5항에 설명합니다.
  • 이용자는 admin@flowads.co.kr로 요청해 YouTube API 서비스로 가져온 자신의 저장 데이터를 삭제할 수 있습니다.

5. 제3자 제공과 처리 위탁

회사는 이용자의 개인정보를 판매하지 않습니다. 서비스 제공에 필요한 범위에서 다음 외부 서비스를 이용합니다.

받는 곳전달되는 정보목적
Google(YouTube Data API)검색어공개 영상 정보 조회
Google Cloud (Google LLC)회원·이용·보안 정보와 공개 YouTube 데이터미국 us-central1 리전 서버에서 서비스 처리 및 메모리 보관
Cloudflare, Inc.IP 주소·요청 경로·접속 시각 등 접속 정보 및 전송 요청 내용전 세계 분산 네트워크를 통한 HTTPS 접속 전달·보안 처리. 로그인 정보도 이 전송 경로를 거칩니다

서비스 접속 시 HTTPS 전송을 통해 Cloudflare의 국제 네트워크를 거쳐 미국 Google Cloud 서버로 요청이 전달됩니다. 검색 시 검색어는 Google의 YouTube API로 전달됩니다. 서비스 계정과 이용 기록은 위 보유 기간 내 처리하며 Cloudflare 자체 접속 메타데이터는 해당 업체의 방침에 따라 처리됩니다. 국외 처리에 관한 문의 및 이용 중단·삭제 요청은 admin@flowads.co.kr로 접수합니다. 이 전송·처리를 원하지 않으면 로그인을 진행하지 않고 서비스를 이용하지 않을 수 있습니다. 현재 심사 데모에는 결제나 일반 회원가입이 없습니다.

영상 미리보기 이미지는 이용자의 브라우저에서 YouTube 이미지 서버로 직접 요청합니다. 이때 IP 주소 등 접속 정보가 Google에 전달될 수 있습니다. Cloudflare는 전송·보안 처리를 위해 접속 정보를 처리하며, 자체 고객 로그와 보유 기간은 Cloudflare 개인정보처리방침을 따릅니다. 회사 애플리케이션은 최종 이용자의 원래 IP를 별도 추출·저장하지 않으며, 프록시 연결 주소와 로그인 이메일 해시로 15분 동안 로그인 시도를 제한합니다.

6. 이용자의 권리

이용자는 언제든지 자신의 개인정보를 조회·수정하거나 처리 정지, 삭제를 요구할 수 있습니다. 저장한 영상은 화면에서 개별 해제할 수 있으며, 계정과 연결된 정보는 로그인 후 계정 삭제 기능으로 삭제할 수 있습니다. 삭제 요청은 admin@flowads.co.kr로도 접수합니다. 서비스에서 삭제해도 YouTube의 원본 정보는 삭제되지 않습니다.

7. 안전조치와 쿠키

  • 외부 접속 전송 구간은 HTTPS로 암호화하고(비공개 검수는 SSH 암호화 연결 사용), 접근 권한은 운영에 필요한 최소 인원에게만 줍니다.
  • 애플리케이션은 로그인·요청 위조 방지를 위한 필수 쿠키를 사용하며 광고·행태정보 수집용 쿠키를 설정하지 않습니다. 브라우저에서 쿠키를 거부하면 로그인 기능을 이용할 수 없습니다. 접속 전달 업체가 서비스 보안에 사용하는 처리는 해당 업체 방침을 따릅니다.
